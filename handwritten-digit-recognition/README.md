\# 🔢 Handwritten Digit Recognition



Created by \*\*The-X-God\*\*



\## 📌 About Project

This Machine Learning project recognizes handwritten digits

from 0 to 9 using the Scikit-learn Digits Dataset.



\## 🛠️ Technologies Used

\- Python

\- NumPy

\- Scikit-learn

\- Matplotlib

\- Random Forest Classifier



\## ⚙️ Model Details

\- Dataset: Scikit-learn Digits Dataset

\- Image Size: 8x8 pixels

\- Algorithm: Random Forest

\- Accuracy: 97.22%
